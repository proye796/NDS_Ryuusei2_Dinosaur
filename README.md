## 추가 기능

받은 것은 저장해야 남습니다. 쓰기 전에 세이브 파일을 따로 복사해 두세요. 자동 저장 중에는 전원을 끄거나 게임을 종료하지 마세요.

### 통신 메뉴

부가 기능 창에서 고른 배포를 원작의 수신 화면으로 받습니다. 배포기의 응답을 게임이 대신합니다.

| 고르는 곳 | 상대 | 내용 |
|---|---|---|
| 부가 기능 창 → 받을 배포 → 배포 카드, 이후 통신 → 게스트로 통신 | 배포 카드 | 「킹그랜저」와 「라 무」 가운데 고른 카드의 배포가 목록에 나옵니다. 선택한 뒤 원작의 수신 화면에서 받습니다. |
| 부가 기능 창 → 받을 배포 → 특별 브라더, 이후 통신 → 게스트로 통신 | 특별 브라더 | 「LM・신」(레전드 마스터 신) 또는 「퍼스트 록맨」을 고릅니다. 등록할 칸을 고르면 브라더가 되고 관련 메일을 받습니다. |
| 부가 기능 창 → 받을 배포 → 대회 크라운, 이후 통신 → 게스트로 통신 | 대회 크라운 | 대회 1·2·3의 블루·실버·골드, 총 9종 가운데 고릅니다. 받으면 내 프로필의 해당 대회 칸에 왕관이 표시됩니다. 대회마다 등급 하나를 기록하며, 더 높은 등급을 받은 뒤에는 낮은 등급을 다시 받지 않습니다. |

배포는 한 번에 하나를 고릅니다. 「받을 배포 → 없음」을 고르면 배포가 목록에서 사라집니다. 고른 배포 항목은 전원을 끄면 초기화되고, 이미 받은 카드·브라더·크라운은 원작의 수신 기록에 따라 중복을 확인합니다.

특별 브라더의 부족은 원작처럼 그 판에 없는 부족으로 정해집니다.

### 부가 기능 창

필드에서 **START를 누른 채 SELECT**(또는 둘을 동시에)를 누르면 부가 기능 창이 열립니다. L·R은 누르지 않은 상태여야 합니다. SELECT만 누르면 원래대로 아래 화면을 바꿉니다. 대화·이동 연출 중에는 열리지 않으며, B나 「그만둔다」로 닫습니다.

| 메뉴 | 항목 | 내용 |
|---|---|---|
| 카드・아이템 | 암호 보상 | 게임 안에 정답 단서가 있는 16개를 제외한 암호 44개의 보상을 한 번에 받습니다. 이미 보상받은 암호는 제외하며, 모두 받았으면 다시 주지 않습니다. |
| 어시스트 | 버스터 | 록 버스터의 보통 샷·차지 샷 공격력 100~500%. 부족별 차지 샷과 어빌리티 버스터에도 적용되며, 배틀 카드는 그대로입니다. |
| | 대미지 | 받는 대미지 경감 0~100%. 20%씩 고르며, 경직·상태 이상은 그대로 일어납니다. |
| | 제니 | 배틀 후 받는 제니 100~500%. 결과 화면 숫자는 원래 금액이고 실제로 받는 돈만 늘어납니다. |
| | HP 회복 | 켜면 이기거나 도망친 배틀 뒤 HP가 최대로 회복됩니다. |
| | 도주 | 켜면 도주가 반드시 성공합니다. 도망칠 수 없는 배틀은 제외합니다. |
| | 인카운터 | 무작위 배틀 빈도: 하지 않음 / 저 / 중 / 고(기본) / 최고. **고가 원래 빈도**이며, 저·중은 더 드물게, 최고는 움직이자마자 배틀이 일어나도록 합니다. 스텔스 보디 사용 중에는 최고 설정의 즉시 조우가 적용되지 않습니다. |
| 받을 배포 | 배포 카드 | 킹그랜저·라 무 중 받을 배포를 고릅니다. 고른 뒤 「통신 → 게스트로 통신」에서 받습니다. |
| | 특별 브라더 | LM・신·퍼스트 록맨 중 고릅니다. 수신 방법은 위 통신 메뉴와 같습니다. |
| | 대회 크라운 | 대회 1·2·3과 블루·실버·골드 등급을 고릅니다. |
| | 없음 | 선택한 배포를 해제합니다. |
| 스타 캐리어 | 모델·레벨 | 스타 캐리어 완구 역할입니다. 모델은 록맨·베르세르크·시노비·다이너소어, 레벨은 LV1·5·10·15·20에서 고릅니다. 맞춘 뒤 아래 순서로 데이터를 받습니다. |
| 에그제 연동 | 켜기·끄기 | GBA 슬롯에 『록맨 에그제』를 꽂았을 때 열리는 원작 연동 이벤트를 켭니다. 일기 5개를 찾아 읽고 마지막 메일에서 「E블래스터」를 받습니다. 보상까지 받았으면 「에그제 연동 이벤트는 이미 끝났어!」가 나옵니다. |

어시스트 설정은 저장하면 남고 **버전별로 따로**입니다. 처음에는 모두 원래 값입니다. 버스터·대미지·HP 회복·도주는 통신 대전과 튜토리얼 전투에서 원래대로이며, 제니 배율도 통신 대전에는 적용하지 않습니다. 인카운터를 「하지 않음」으로 해도 이야기의 전투와, 다른 부족의 브라더가 생긴 뒤 나오는 더블 트라이브 튜토리얼은 그대로 진행됩니다.

### 스타 캐리어 받기

1. 부가 기능 창 → 「스타 캐리어」에서 모델과 레벨을 맞춥니다.
2. 트랜서의 **워록 화면에서 SELECT**를 누르고 「웨이브 커맨드 카드를 쓸 거지?」에 예를 고릅니다.
3. 입력 화면에서 **아무 칸도 누르지 않은 채 Y**를 누릅니다. 스타 캐리어 코드 여섯 칸이 자동으로 입력되고, 원작의 데이터 수신·저장으로 이어집니다.
4. 받은 뒤에는 **워록 화면 → 오른쪽의 스타 캐리어 화면**에서 강화 ON/OFF와 데이터 삭제를 할 수 있습니다.

부가 기능 창에서 맞춘 모델·레벨은 전원을 끄면 사라집니다. 게임 안에서 받아 저장한 스타 캐리어 데이터는 남습니다. 카드 박스에서 연 입력 화면이나, 모델·레벨을 아직 맞추지 않은 상태에서는 Y로 입력되지 않습니다.

### 에그제 연동 이벤트

필드에서 **START+SELECT → 에그제 연동 → 예**를 고르면 켜집니다. GBA 카트리지 없이도 원작 연동 이벤트를 진행할 수 있습니다. 실제 에그제 카트리지의 인식 기능도 그대로입니다.

1. 이야기의 진행 조건을 갖추면 사테라폴리스의 안내 메일이 옵니다. 이미 조건을 갖춘 세이브는 필드에서 잠시 기다리면 됩니다.
2. 전파 세계에서 오래된 데이터를 찾아 바이러스를 물리치고, **1월·3월·7월·9월·11월의 일기 5개**를 모읍니다. 켜거나 끈 직후에는 해당 맵을 나갔다 다시 들어오세요.
3. 모은 일기를 아이템 화면에서 **모두 읽으면** 히카리 넷토의 메일이 옵니다. 메일을 읽어 워록 장비 「E블래스터」를 받습니다.
4. E블래스터까지 받은 뒤 「에그제 연동」을 다시 고르면 **「에그제 연동 이벤트는 이미 끝났어!」**라고 나옵니다. 완료한 이벤트와 보상을 다시 시작하지 않습니다.

진행 중에는 같은 메뉴에서 끌 수 있습니다. 껐다 켜도 모은 일기·읽은 기록·이미 받은 메일과 보상은 남습니다. 연동 설정과 진행은 **버전별로 따로**이며, 설정을 바꾼 뒤에는 게임을 저장하세요. 실제 에그제 카트리지가 꽂혀 있으면 다음에 켤 때 원작대로 연동이 켜집니다.

### 암호 목록 메일

레전드 마스터 신의 암호 소개 메일 「레전드한 소식!」을 받으면, 보낸 이가 「LM・신」인 **「암호 목록」** 메일도 받습니다. 이미 소개 메일을 받은 세이브라면 필드를 조금 걸으면 도착합니다.

게임 안에 정답 단서가 있는 암호 16개와 사용법이 들어 있습니다. 신에게 **제목 「암호」, 본문에 암호의 답**을 적어 보내면 원작대로 보상을 받습니다. 부가 기능 창의 「암호 보상」에서 제외한 16개가 이 목록에 해당합니다.
